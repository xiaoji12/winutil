## 一般问题

### 还支持 Windows 10 吗？

不支持。WinUtil 已不再支持 Windows 10，因为 Windows 10 已于 **2025 年 10 月 14 日**终止支持。WinUtil 目前专注于 Windows 11。

### 如何卸载 WinUtil？

你不需要卸载 WinUtil。它以 PowerShell 脚本的形式运行，只在打开期间被加载到内存中。关闭之后，它就会从内存中移除，不会残留安装在你的系统上。

### WinUtil 使用安全吗？

安全，WinUtil 是开源项目，代码公开在 GitHub 上，每天都有成千上万的用户在运行它。不过，与任何系统修改工具一样，你应该：

- 以管理员身份运行（必需）
- 进行重大更改前创建还原点
- 了解自己正在应用哪些优化项
- 只从[官方来源](https://github.com/ChrisTitusTech/winutil/)运行

### 需要一直运行 WinUtil 吗？

不需要。应用优化项或安装完应用程序后，你就可以关闭 WinUtil，所做的更改在关闭后依然保留。只有在想要进行更多更改或撤销优化项时，才需要再次运行 WinUtil。

### WinUtil 需要联网吗？

- **下载时**：需要，安装应用程序必须联网
- **应用优化项时**：不需要，大多数优化项可离线使用
- **首次运行时**：需要，以便运行最新的脚本

### WinUtil 多久更新一次？

WinUtil 维护活跃，更新频繁。新功能、错误修复和新增应用程序都会定期发布。脚本每次运行时都会自动下载最新版本。

## 安装与运行

### 如何运行 WinUtil？

1. 以管理员身份打开 PowerShell
2. 运行：`irm "https://christitus.com/win" | iex`
3. 等待图形界面出现

### 为什么需要管理员权限？

WinUtil 会进行系统级更改（修改注册表、调整服务、安装软件），这些操作都需要提升的权限。没有管理员权限，大多数功能都无法正常工作。

### 脚本下载不了，怎么办？

请按顺序尝试以下解决办法：

1. **使用 GitHub 直接链接**：

   ```powershell
   irm https://github.com/ChrisTitusTech/winutil/releases/latest/download/Winutil.ps1 | iex
   ```

2. **强制使用 TLS 1.2**：

   ```powershell
   [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
   irm "https://christitus.com/win" | iex
   ```

   :::note
   在 Windows 11 上，通常不需要使用 TLS 1.2 命令。只有在遇到下载或安全协议错误时才使用它。
   :::

3. **更换 DNS** 为 Cloudflare（1.1.1.1）或 Google（8.8.8.8）
4. **使用 VPN**（如果你所在地区无法访问 GitHub）

### 出现「执行策略」错误，如何解决？

先运行下面这条命令以允许脚本执行：

```powershell
Set-ExecutionPolicy Unrestricted -Scope Process -Force
irm "https://christitus.com/win" | iex
```

这只会影响当前的 PowerShell 会话，是安全的。

## 优化项与系统修改

### 应用了某个优化项后出问题了，怎么办？

如果你应用了某个优化项并导致故障，可以将其还原：

1. 再次打开 WinUtil
2. 进入**优化项**标签页
3. 选中你应用过的同一个优化项
4. 点击**撤销所选优化项**
5. 系统会恢复到之前的状态

或者，如果你创建过还原点，可以使用系统还原。

### 哪些优化项是安全的？

**所有人都可以放心使用（常规优化项）**：

- 禁用遥测
- 禁用活动历史记录
- 禁用位置跟踪
- 删除临时文件
- 运行磁盘清理
- 创建还原点

**高级优化项**只应由高级用户使用。

### 优化项在 Windows 更新后还有效吗？

大多数优化项在更新后依然保留，但某些优化项可能会被 Windows 的重大功能更新重置。之后你可能需要重新应用部分优化项。

### 可以创建自己的优化项预设吗？

目前 WinUtil 使用的是预定义预设（Standard、Minimal）。图形界面暂不直接支持自定义预设，但你可以用脚本来实现自己偏好的配置。

### 常规优化项和高级优化项有什么区别？

- **常规优化项**：对大多数用户安全，能提升性能与隐私保护，风险极低
- **高级优化项**：改动更激进，可能影响功能或兼容性。请谨慎使用。

## 应用程序安装

### WinUtil 是如何安装应用程序的？

WinUtil 使用 Windows 程序包管理器（WinGet）和 Chocolatey 来自动完成安装。它从官方来源下载应用程序，并以静默方式安装，不附带任何预装冗余软件。

### 可以同时安装多个应用程序吗？

可以！勾选你想要的所有应用程序，然后点击「安装所选」，它们会按顺序依次安装。

### WinGet 无法使用，如何修复？

1. 进入**配置**标签页
2. 找到**修复**部分
3. 点击**重新安装 WinGet**
4. 等待完成
5. 再次尝试安装应用程序

### 安装的应用程序会带预装冗余软件或捆绑程序吗？

不会。WinGet 和 Chocolatey 安装的都是应用程序的干净版本，没有捆绑推广、工具栏或冗余软件。

### 可以通过 WinUtil 卸载应用程序吗？

WinUtil 主要专注于安装和管理应用程序，并没有为卸载每一个程序提供完整的图形界面。要移除应用程序，你可以：

- 使用 Windows 设置 > 应用 > 已安装的应用来卸载程序。
- 在 PowerShell 中使用包管理器命令（例如 `winget uninstall <package>` 或 `choco uninstall <package>`）。
- WinUtil 安装的某些包（AppX/MSIX）带有移除辅助功能；请查看该应用条目，或在可用时使用 WinUtil 的移除辅助功能。

### 已安装的应用程序会自动更新吗？

带有内置更新机制的应用程序会自动更新。你也可以通过 WinGet/Chocolatey 命令或 WinUtil 的「升级所选」功能来更新它们。

## 更新与维护

### 应该禁用 Windows 更新吗？

一般来说**不应该**。安全更新很重要。不过你可以：

- 使用「仅安全更新」来避开功能更新
- 为保持稳定临时暂停更新
- 仅在处理关键工作期间禁用更新

### 禁用更新后如何重新启用？

1. 打开 WinUtil
2. 进入**更新**标签页
3. 点击**默认更新**
4. 更新将恢复正常

### 「仅安全更新」和「禁用更新」有什么区别？

- **仅安全更新**：安装关键安全补丁，阻止功能更新（大版本）
- **禁用更新**：阻止**所有**更新，包括安全更新（不推荐）

## 故障排查

### 运行命令后 WinUtil 打不开

可能的原因：

1. **杀毒软件拦截**：为 PowerShell 添加例外
2. **未以管理员身份运行**：以管理员身份重新启动 PowerShell
3. **下载文件损坏**：关闭 PowerShell，重新打开后再试一次
4. **Windows Defender**：允许该脚本运行

### 我的杀毒软件把 WinUtil 报成恶意软件

这是误报。WinUtil 会进行系统更改，杀毒软件可能会因此报警。代码是开源的，可以接受审查。如有需要，请添加例外。

### 某个应用程序安装失败

排查步骤：

1. 检查网络连接
2. 尝试只安装这一个应用程序
3. 查看输出面板中的错误信息
4. 检查是否被杀毒软件拦截
5. 尝试「重新安装 WinGet」修复

### 网络优化项导致我的网络连接中断

1. 打开 WinUtil
2. 进入**配置** > **修复**
3. 点击**重置网络**
4. 重启电脑
5. 连接应该会恢复

### 应用优化项后某些 Windows 功能无法使用

撤销可能影响到这些功能的优化项：

1. 重新打开 WinUtil
2. 选中你应用过的优化项
3. 点击**撤销所选优化项**

如果这样不起作用，请使用系统还原回到之前的状态。

## 高级话题

### WinUtil 可以在 Windows Server 上运行吗？

可以，WinUtil 能在 Windows Server 版本上运行，不过部分功能可能不适用或表现有所不同。

### WinUtil 支持 Windows LTSC 吗？

WinUtil 目前面向 Windows 11。按照上面提到的 Windows 10 支持策略，Windows 10 LTSC 不受支持。部分功能和应用程序可能因 Windows 11 的版本不同而有差异。

### 可以在企业/公司环境中使用 WinUtil 吗？

可以，但请先确认你所在组织的相关策略。某些优化项可能与组策略或其他企业要求相冲突。

## 隐私与安全

### WinUtil 会收集数据吗？

不会，WinUtil 本身不收集或传输任何用户数据。它是一个本地 PowerShell 脚本。

### 「禁用遥测」优化项会屏蔽哪些遥测？

它会禁用：

- Windows 诊断数据收集
- 活动历史记录跟踪
- 反馈请求
- 使用情况统计
- 错误报告（可选）

### 移除 Microsoft Store 会影响安全更新吗？

不会，Windows 安全更新与 Microsoft Store 相互独立。

## 性能

### WinUtil 会让我的电脑变快吗？

优化项可以通过以下方式提升性能：

- 减少后台进程
- 禁用不必要的服务
- 清理临时文件
- 优化开机启动项

具体效果因系统而异。

### 玩游戏最适合用哪个预设？

使用 **Desktop** 预设，然后再额外应用：

- 禁用 GameDVR
- 卓越性能电源计划
- 禁用全屏优化（高级）
- 将显示设置为性能优先（高级）

### WinUtil 占用多少内存？

WinUtil 运行时自身大约占用 50-100 MB。关闭后就会从内存中移除。

## 错误提示

### 「拒绝访问」错误

- 确认 PowerShell 正以管理员身份运行
- 检查杀毒软件是否拦截了更改
- 确认你拥有相关文件/注册表项的所有权
