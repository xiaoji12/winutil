## 欢迎使用 WinUtil！

WinUtil 可以帮你在一个地方完成安装应用、应用系统优化项、执行常见修复以及管理 Windows 设置。本指南介绍最稳妥的上手方式，以及大多数用户最先做的几件事。

## 系统要求

运行 WinUtil 之前，请确保你的系统满足以下要求：

:::caution
WinUtil 不支持 Windows 10。Windows 10 已于 **2025 年 10 月 14 日**终止支持。
:::

- **操作系统**：Windows 11
- **PowerShell**：5.1 或更高版本（Windows 11 默认已自带）
- **管理员权限**：进行系统级更改时必需
- **网络连接**：下载应用程序和更新时需要
- **.NET Framework**：4.5 或更高版本（通常已预装）

## 安装

WinUtil 不需要传统的安装过程。它作为脚本直接在 PowerShell 中运行。

### 步骤 1：以管理员身份打开 PowerShell

有多种方式可以打开具备管理员权限的 PowerShell：

**方法 1：开始菜单（推荐）**

1. 右键点击 Windows 开始按钮。
2. 选择「终端（管理员）」。

**方法 2：搜索方式**

1. 按下 `Windows` 键。
2. 输入「PowerShell」或「终端」。
3. 按 `Ctrl + Shift + Enter` 以管理员身份启动。
4. 或者右键点击并选择「以管理员身份运行」。

**方法 3：运行对话框**

1. 按下 `Windows + R`。
2. 输入 `powershell`。
3. 按 `Ctrl + Shift + Enter`。

### 步骤 2：运行启动命令

在以管理员身份运行的 PowerShell 中，根据你需要的发布渠道运行以下某个命令。

**稳定版（推荐）**

```powershell
irm "https://christitus.com/win" | iex
```

**开发分支（最前沿 —— 仅供测试）**

```powershell
irm "https://christitus.com/windev" | iex
```

:::note
- `irm` 命令用于下载脚本，`iex` 用于执行它。从官方来源下载时这是安全的。
- 开发分支可能包含实验性改动，只应在非生产系统上用于测试。
:::

### 步骤 3：等待 WinUtil 加载

首次运行 WinUtil 时，可能需要一点时间来完成：

- 下载最新版本
- 初始化界面
- 加载所有功能与设置

## 首次设置

### 了解界面

WinUtil 打开后是一个清爽的标签式界面：

**主要标签页**：

- **安装**：浏览并安装应用程序
- **优化项**：应用系统优化与个性化设置
- **配置**：使用系统工具和实用程序
- **更新**：管理 Windows 更新
- **Win11 镜像制作**：基于官方 Microsoft 镜像制作定制化的 Windows 11 ISO

## 你的第一步操作

以下是给新用户的一些推荐步骤：

### 1. 创建还原点

在做任何更改之前，先创建系统还原点：

1. 进入**优化项**标签页。
2. 在常规优化项中找到「创建还原点」。
3. 勾选它并点击**运行优化项**。

这样你就有了必要时的回退点。

### 2. 安装必备应用程序

1. 进入**安装**标签页。
2. 浏览分类或使用搜索栏。
3. 勾选你想安装的应用程序。
4. 点击底部的「安装/升级所选」。

### 3. 应用基础优化项

以最小的风险获得更好的 Windows 体验：

1. 进入**优化项**标签页。
2. 选择 **Standard** 预设，获得一套均衡的配置。
3. 检查被选中的优化项。
4. 点击**运行优化项**。

:::note
某些优化项、修复和更新改动可能需要重启或注销后才会完全生效。
:::

## 常见操作

### 安装应用程序

**单个应用程序**：

1. 打开**安装**标签页。
2. 搜索应用程序名称。
3. 勾选它前面的复选框。
4. 点击「安装/升级所选」。

**多个应用程序**：

1. 勾选多个应用程序。
2. 所有已勾选的应用会按顺序依次安装。
3. 安装与卸载进度会显示在窗口底部的面板中，包括当前的软件包或包管理器批次，以及整体完成情况。

### 应用优化项

**常规优化项**（对所有用户都安全）：

1. 进入**优化项**标签页。
2. 在常规优化项部分进行选择。
3. 点击**运行优化项**。

**高级优化项**（请谨慎使用）：

1. 只有在了解其影响后才去修改。
2. 务必先创建还原点。
3. 查阅每个优化项的说明文档。

**撤销优化项**：

1. 选中你应用过的相同优化项。
2. 点击**撤销所选优化项**。
3. 系统会恢复到之前的状态。

### 使用快速修复

针对常见的 Windows 问题：

1. 进入**配置**标签页。
2. 找到**修复**部分。
3. 选择合适的修复项：
   - **重置网络**：修复网络连接问题
   - **重置 Windows 更新**：解决更新相关故障
   - **系统损坏扫描**：修复损坏的系统文件
   - **重新安装 WinGet**：解决包管理器问题

### 更改 DNS 服务器

为了提升隐私和速度：

1. 进入**优化项**标签页。
2. 找到 DNS 部分。
3. 选择服务商：
   - **Cloudflare**：速度快且注重隐私
   - **Google**：稳定可靠、使用广泛
   - **Quad9**：注重安全，可拦截恶意软件
   - **AdGuard**：拦截广告与跟踪器
4. 点击**应用**。

## 了解预设

WinUtil 提供以下几种预设配置：

- **Minimal**：改动最小，保留大部分 Windows 功能
- **Standard**：对大多数用户来说恰到好处的折中方案
- **Advanced**：精选一组更安全的高级优化项

## 安全提示

✅ **应该做的**：

- 进行重大更改前创建还原点
- 应用前先阅读优化项的说明
- 先从常规优化项开始
- 保持 Windows 处于最新状态
- 备份重要数据

❌ **不应该做的**：

- 在不了解作用的情况下一次性应用全部优化项
- 跳过创建还原点这一步
- 不做功课就使用高级优化项
- 除非必要，否则不要禁用安全功能
- 未经测试就在生产系统上运行

## 首次运行的故障排查

### 脚本无法下载

如果启动命令失败：

- 确认 PowerShell 或终端正以管理员身份运行。
- 确认电脑可以上网，并且能够访问 `christitus.com`。
- 改用普通的 PowerShell 会话重试，而不是受限的企业 shell 配置文件。
- 如果命令启动后立即关闭，请以管理员身份重新打开终端再运行一次，以便看到错误输出。

如果仍然失败，请查看[已知问题](/knownissues/)页面。

## 导出诊断报告

如果你要反馈问题，请点击右上角的齿轮图标并选择**导出环境报告**。它会保存一份只读的 JSON 文件，其中包含：

- Windows 版本、版本号、内部版本和系统架构
- CPU 型号、逻辑处理器数量和内存总量
- PowerShell 版本、版本号和执行策略
- 是否安装了 WinGet 和 Chocolatey，以及它们的版本
- 是否有待处理的重启
- 每一个优化项和开关当前「已应用/未应用」的状态

其中不包含计算机名或用户名、路径、IP 或 MAC 地址、序列号、已安装应用清单、服务、原始注册表路径或键值、密钥或日志。优化项/开关的状态来自注册表比对，但只包含每个优化项最终的 true/false 结果，不包含任何注册表内容本身。WinUtil 绝不会上传该报告 —— 保存位置和发送对象都由你自己决定。

系统会询问你是否同时把最近 7 天的 WinUtil 日志打包成一个配套的 `.txt` 文件，维护者在排查问题时通常需要将它与报告一起查看。这个配套文件是原始日志输出，不适用 JSON 报告的隐私白名单：它可能包含本地路径、命令和错误详情。分享前请先检查。
