使用**功能**和**修复**部分来安装可选的 Windows 组件，并执行常见的修复任务。

本页对应 WinUtil 中的**配置**标签页。有些操作会立即完成，有些则可能会弹出提示、从 Microsoft 下载文件，或者需要重启后更改才会完全生效。

![Config tab with features and fixes](../../../assets/screenshots/config-tab-new.png)

## Windows 功能

勾选相应的功能复选框并点击**安装功能**，即可安装常用的 **Windows 功能**。

如果某个功能依赖 Windows 安装介质或可选下载内容，Windows 可能需要更长时间才能完成，或要求重启。

* 所有 .NET Framework 版本（2、3、4）
* Hyper-V 虚拟化
* 旧版媒体功能（WMP、DirectPlay）
* NFS - 网络文件系统
* 启用每日注册表备份任务（凌晨 12:30）
* 启用旧版 F8 启动恢复
* 禁用旧版 F8 启动恢复
* Windows Subsystem for Linux
* Windows Sandbox

## 修复

用这些一键修复来解决常见的系统问题。

请在遇到具体问题时使用它们，而不要当成常规的清理步骤。

* 设置自动登录
* 重置 Windows 更新
* 重置网络
* 系统损坏扫描
* 重新安装 WinGet

## 旧版 Windows 面板

直接从 WinUtil 打开传统风格的 Windows 面板。可用的面板包括：

* 控制面板
* 网络连接
* 电源面板
* 区域
* 声音设置
* 系统属性
* 用户账户

## 远程访问

在你的 Windows 电脑上启用 OpenSSH 服务器，以便远程访问。

只有在你确实需要使用远程 shell 访问时才启用它。开启之后，在把这台电脑暴露给其他设备之前，请先确认防火墙规则和账户权限。

由于 WinUtil 以提升的权限运行，它设置的账户是管理员账户，而 sshd 会从 `C:\ProgramData\ssh\administrators_authorized_keys` 而不是从你的用户配置目录读取管理员密钥。WinUtil 会创建该文件并将其权限限制为 Administrators 和 SYSTEM，这正是 sshd 所要求的。请把你的公钥添加到那里。如果早期版本的 WinUtil 曾把 `sshd_config` 改为从 `%USERPROFILE%\.ssh\authorized_keys` 读取管理员密钥，该改动会被撤销，其中的密钥也会被复制过去，因此密钥认证可以继续正常工作。

非管理员账户仍继续使用 `%USERPROFILE%\.ssh\authorized_keys`，无需额外设置。
