:::caution
WinUtil 不支持 Windows 10。Windows 10 已于 **2025 年 10 月 14 日**终止支持。
:::

## WinUtil 是什么？

WinUtil（Chris Titus Tech 的 Windows 实用工具）是一个基于 PowerShell 的综合性工具，可以帮你：

- **安装应用程序**：快速安装常用软件，无需手动下载
- **应用优化项**：针对性能、隐私和易用性优化 Windows
- **修复问题**：通过一键修复排查常见的 Windows 故障
- **管理更新**：控制 Windows 更新的安装方式和时机
- **使用工具**：快速打开 Windows 的各种面板与实用程序

## 谁适合使用 WinUtil？

WinUtil 面向以下人群：

- **家庭用户**：想优化自己个人电脑的人
- **高级用户**：希望对 Windows 进行精细控制的用户
- **IT 专业人员**：需要高效管理多台系统的团队
- **游戏玩家**：为游戏性能而优化系统的用户
- **注重隐私的用户**：希望减少遥测和数据收集的人
- **开发人员**：需要搭建干净开发环境的用户

## 安全与最佳实践

使用 WinUtil 之前：

✅ **务必做到**：
- 以管理员身份运行 PowerShell
- 进行重大更改前创建系统还原点
- 应用优化项前先了解它的作用
- 先使用常规优化项，再考虑高级优化项
- 为重要数据保留备份

❌ **切勿**：
- 在不了解作用的情况下应用全部优化项
- 跳过创建还原点这一步
- 未经测试就在生产系统上使用
- 不必要地禁用安全功能

## 系统要求

- **操作系统**：Windows 11
- **PowerShell**：5.1 或更高版本（Windows 11 已自带）
- **权限**：需要管理员权限
- **网络**：下载应用和更新时需要联网
- **.NET Framework**：4.5 以上（通常已预装）
