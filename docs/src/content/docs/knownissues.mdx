### 无法下载

如果你运行 WinUtil 时出现类似下面的错误：

`< : The term '<' is not recognized as the name of a cmdlet, function, script file, or operable program.`

请尝试使用 **VPN**；如果仍然不行，请到 https://github.com/ChrisTitusTech/winutil/issues 反馈该问题。

### 脚本无法运行

如果你运行 WinUtil 时出现以下错误：

`"WinUtil is unable to run on your system. PowerShell execution is restricted by security policies"`

这说明你的 PowerShell 会话处于**受约束语言模式**，它会阻止 WinUtil 运行。

### 卓越性能电源计划无效

在部分不完全支持该电源计划的笔记本上，卓越性能电源计划可能无法生效。

在这些情况下，该电源计划可能会应用失败。在不受支持的硬件上，这是预期行为。

### 「还原开始菜单」优化项失效

从 **Windows 11 更新 KB5089573**（2026 年 5 月发布）开始，「还原开始菜单」优化项不再有效。

在该更新中，Microsoft 已彻底从 Windows 中移除旧版开始菜单的代码，因此我们无法再将其恢复。

### PowerShell 7 相关问题或「类未注册」错误
已知从 Microsoft Store 安装 PowerShell 7（MSIX 包）会导致 `Get-WindowsOptionalFeature`、`Enable-WindowsOptionalFeature` 等 DISM cmdlet 出现问题，并产生 `Class not registered` 的 COM 错误。

这也可能导致「移除预装应用」耗时无限延长。

请改用以下方式之一安装 PowerShell 7：

**winget（推荐）：**
```powershell
winget install --id Microsoft.PowerShell --source winget --installer-type wix
```
**从 GitHub Releases 直接下载 MSI：** 从 [PowerShell GitHub Releases](https://github.com/PowerShell/PowerShell/releases) 页面下载 `.msi` 安装程序。

详情请参阅 https://github.com/PowerShell/PowerShell/issues/13866
