## 注册表更改

应用和系统组件通过读写配置数据来修改 Windows 设置，因此我们可以借助注册表在一处集中更改众多设置。

你可以在 [Wikipedia](https://en.wikipedia.org/wiki/Windows_Registry) 和 [Microsoft 官网](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry) 上查阅有关注册表的更多信息。
