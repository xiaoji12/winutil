```json title="config/tweaks.json"
  "WPFTweaksConsumerFeatures": {
    "Content": "ConsumerFeatures - Disable",
    "Description": "Stops promoted app installs and reduces app suggestions from Microsoft Store content.",
    "category": "Essential Tweaks",
    "panel": "1",
    "registry": [
      {
        "Path": "HKLM:\\SOFTWARE\\Policies\\Microsoft\\Windows\\CloudContent",
        "Name": "DisableWindowsConsumerFeatures",
        "Value": "1",
        "Type": "DWord",
        "OriginalValue": "<RemoveEntry>"
      }
    ],
  }
```

## 注册表更改

应用和系统组件通过读写配置数据来修改 Windows 设置，因此我们可以借助注册表在一处集中更改众多设置。

你可以在 [Wikipedia](https://en.wikipedia.org/wiki/Windows_Registry) 和 [Microsoft 官网](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry) 上查阅有关注册表的更多信息。
