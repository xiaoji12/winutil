:::note
本页由 [`config/tweaks.json`](https://github.com/ChrisTitusTech/winutil/blob/main/config/tweaks.json) 自动生成。请勿直接编辑本页。
:::

```json title="config/tweaks.json"
  "WPFTweaksEndTaskOnTaskbar": {
    "Content": "End Task With Right Click - Enable",
    "Description": "Enables option to end task when right-clicking a program in the taskbar.",
    "category": "Essential Tweaks",
    "panel": "1",
    "registry": [
      {
        "Path": "HKCU:\\Software\\Microsoft\\Windows\\CurrentVersion\\Explorer\\Advanced\\TaskbarDeveloperSettings",
        "Name": "TaskbarEndTask",
        "Value": "1",
        "Type": "DWord",
        "OriginalValue": "<RemoveEntry>"
      }
    ],
  }
```

## 注册表更改

应用和系统组件通过读写配置数据来修改 Windows 设置，因此我们可以借助注册表在一处集中更改众多设置。

你可以在 [Wikipedia](https://en.wikipedia.org/wiki/Windows_Registry) 和 [Microsoft 官网](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry) 上查阅有关注册表的更多信息。
